Method and assumptions

Losses. S = 25400/CN − 254 (mm), initial loss Ia = ratio × S, and runoff Q = (P − Ia)² / (P − Ia + S) for P > Ia, applied to cumulative rainfall. With ratio 0.2 this is the textbook (P − 0.2S)² / (P + 0.8S). Dry and wet soil use the standard conversions of the normal curve number.

Unit hydrograph. SCS triangular: lag = 0.6 tc, time to peak Tp = dt/2 + lag, peak Qp = 0.208 A / Tp (m³/s per mm), base time 2.67 Tp. Ordinates are scaled slightly so the volume is exactly A × 1000 m³ per mm of runoff.

Hydrograph. The runoff of every time step is convolved with the unit hydrograph, and the baseflow is added.

Limits. The catchment is treated as one lump, the response is assumed linear, the triangle is an approximation, and the curve number does not change during the storm. Use dt ≤ 0.133 tc for a smooth result.
